# `src/rulesets` — Плагины правил и общие генераторы ходов

Здесь живёт всё «знание об игре». Ядро предоставляет контракты, этот слой их реализует: сначала — generic-механики, пригодные для любой игры, затем — конкретный набор правил (шахматы и вариации).

## Структура

```
rulesets/
├── movement.ts        # generic-генератор ходов по MovementPattern
├── geometry.ts        # ориентация доски (forward/home/promotion) для ruleset'ов
├── chess-ruleset.ts   # реализация RuleSet для шахмат (и база для вариаций)
└── chess/             # декларативные данные шахматного набора правил
    ├── config.ts      # конфигурация ChessRuleSet (стандарт/FIDE + вариации)
    ├── pieces.ts      # словарь фигур FIDE (типы, имена, ценности, расстановка)
    └── patterns.ts    # модели движения фигур (дельты направлений)
```

## Файлы общего уровня

| Файл | Содержание |
|---|---|
| [`movement.ts`](./movement.ts) | Топология-агностичный генератор: превращает объявления `MovementPattern` в список целевых позиций. Границы и занятость запрашивает у доски; поддерживает хук `DirectionMapper` (`identityDirectionMapper` по умолчанию) для перенаправления символьных дельт (например «вперёд» для пешки). |
| [`geometry.ts`](./geometry.ts) | `OrientedBoard` — минимальный контракт ориентированной доски (`forwardOf`, `homeRankOf`, `pawnStartRankOf`, `promotionRankOf`). Сознательно **не** часть ядра `Topology`: шахматная семантика остаётся инъектируемой и тестируемой (достаточно тестового двойника с этими методами). |

## Набор правил «Шахматы»

| Файл | Содержание |
|---|---|
| [`chess-ruleset.ts`](./chess-ruleset.ts) | Реализация `RuleSet`: начальная расстановка, валидация ходов (специальные правила — рокировка, взятие на проходе, превращение — несут данные в `Move.metadata`), генерация псевдолегальных ходов через `generatePatternTargets`, детект конца игры. Ориентацию берёт из `OrientedBoard`, не захардкодивая её. |
| [`chess/config.ts`](./chess/config.ts) | `ChessRuleSetConfig`: дефолты воспроизводят стандарт FIDE (id игроков `'white'/'black'`); вариации (Капабланка, большие доски) переопределяют фигуры/паттерны/ориентацию/extents без наследования. |
| [`chess/pieces.ts`](./chess/pieces.ts) | Чистые данные: `CHESS_PIECES`, материальные ценности, начальная расстановка заднего ряда. Никаких правил; вариации расширяют через `withExtraPieces`. |
| [`chess/patterns.ts`](./chess/patterns.ts) | Декларативная геометрия ходов. Все дельты абсолютные, кроме пешки: она использует символьный `FORWARD`, который ruleset разрешает через `forwardOf(player)` — единственный ориентационно-зависимый элемент. |

## Как добавить свою игру

1. Создайте директорию-аналог `mygame/` со словарём фигур и паттернами (данные без правил).
2. Реализуйте интерфейс `RuleSet` из [`../core/ruleset.ts`](../core/ruleset.ts), переиспользуя [`movement.ts`](./movement.ts).
3. Если нужны направления относительно игрока — расширьте контракт `OrientedBoard`, не ядро.

## Правила зависимостей

- ✅ Зависит от `core`, `topology`, `state`.
- ❌ Ядро никогда не зависит от `rulesets` — направление импортов строго однослойное.
