# `src/rulesets/chess` — Данные шахматного набора правил

Чистые **декларативные данные** для `ChessRuleSet`: словарь фигур, модели движения и конфигурация. Поведение (валидация, расстановка, специальные правила) живёт на уровень выше — в [`../chess-ruleset.ts`](../chess-ruleset.ts), который потребляет этот модуль.

## Файлы

| Файл | Содержание |
|---|---|
| [`pieces.ts`](./pieces.ts) | Словарь фигур FIDE: константы `CHESS_PIECES`, типы `ChessPieceName` / `ChessPieceId`, материальные ценности (`ChessPieceSpec`) и начальная расстановка заднего ряда. Включает `withExtraPieces` для расширения вариациями (Капабланка и т.п.). Правил здесь нет. |
| [`patterns.ts`](./patterns.ts) | Декларативные `MovementPattern` для всех фигур (ортогонали, диагонали, ходы коня). Дельты абсолютные; единственный ориентационный элемент — символьный `FORWARD` у пешки, разрешаемый через `OrientedBoard.forwardOf()` хуком `mapDirection` генератора из [`../movement.ts`](../movement.ts). |
| [`config.ts`](./config.ts) | `ChessRuleSetConfig` + вспомогательные типы `ChessOrientation`, `BoardExtents`. Дефолты = стандарт FIDE с legacy-id игроков `'white'/'black'`; вариации переопределяют фигуры/паттерны/ориентацию/границы доски **без наследования**. |

## Принципы

- **Данные ≠ правила.** Этот каталог можно сериализовать/заменить целиком, не трогая код движка.
- **Варианты через конфигурацию, а не подклассы.** Новый вариант шахмат = новый `ChessRuleSetConfig` (+ при необходимости расширенный словарь фигур/паттернов).
- **Нет зависимости от конкретной топологии.** Паттерны оперируют числовыми дельтами; границы проверяет доска.
