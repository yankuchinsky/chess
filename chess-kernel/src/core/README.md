# `src/core` — Ядерные примитивы движка

Базовый слой chess-kernel. Содержит только абстрактные типы и утилиты, **не знающие ничего о правилах конкретной игры**: ни о доске 8×8, ни о пешках, ни о ходах коня. Всё «игровое знание» живёт в `src/rulesets`.

## Назначение слоя

- Определить универсальные словари сущностей: идентификаторы, координаты, фигуры, направления.
- Задать контракты (`interface`), которые реализуют остальные слои: `RuleSet`, `PieceDefinition`, `MovementPattern`.
- Гарантировать неизменяемость базовых объектов (`Object.freeze`).

## Файлы

| Файл | Содержание |
|---|---|
| [`types.ts`](./types.ts) | Базовые алиасы и утилиты: `EntityId`, `PlayerId`, `PieceType`, `Coordinate`, `Position` (топология-агностичные координаты), фабрика `createPosition`, сравнение `positionsEqual`. |
| [`direction.ts`](./direction.ts) | Направления перемещения: `Direction`, `DirectionDelta`, `createDirection`, `applyDirection`, `directionsEqual`, `reverseDirection`. |
| [`piece.ts`](./piece.ts) | Абстрактная фигура `Piece` (id, тип, владелец, опциональная позиция — без позиции «в руке»), фабрика `createPiece`, функциональное обновление `transformPiece`. |
| [`ruleset.ts`](./ruleset.ts) | Контракты плагинов правил: `PieceDefinition`, `DirectionSpec`, `MovementPattern` и главный интерфейс `RuleSet` (валидация ходов, расстановка, определение конца игры). |

## Правила зависимостей

- ✅ `core` не импортирует ничего из `topology`, `state`, `rulesets` (кроме собственных модулей).
- ⚠️ Исключение: `ruleset.ts` ссылается на типы `Board`/`Topology`/`Move`/`GameState` как на *контракты* — при рефакторинге допустимо вынести эти интерфейсы в отдельные файлы-контракты, но направление «правила → ядро» менять нельзя.

## Связь с другими слоями

`rulesets/*` и `topology/*` реализуют интерфейсы из этого пакета; публичный API перекрывается через [`../index.ts`](../index.ts).
