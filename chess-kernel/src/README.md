# `src/` — Исходный код chess-kernel

Документация распределена по слоям (подход *directory-level docs*: каждый каталог описывает свою ответственность, контракты и правила зависимостей).

## Карта каталогов

| Каталог | Ответственность | Документация |
|---|---|---|
| [`core/`](./core/README.md) | Абстрактные типы и контракты без знания о правилах (`Position`, `Piece`, `RuleSet`, направления) | [README](./core/README.md) |
| [`topology/`](./topology/README.md) | Доска, клетки, формы поля (прямоугольник, гекс, произвольная) | [README](./topology/README.md) |
| [`state/`](./state/README.md) | Неизменяемое состояние партии, ходы, история | [README](./state/README.md) |
| [`rulesets/`](./rulesets/README.md) | Генераторы ходов, ориентация доски, набор правил «шахматы» | [README](./rulesets/README.md) |
| [`rulesets/chess/`](./rulesets/chess/README.md) | Декларативные данные шахмат: фигуры, паттерны, конфигурация | [README](./rulesets/chess/README.md) |

## Направление зависимостей (строго однослойное)

```
core  ←  topology  ←  state  ←  rulesets
(ядро ничего не знает о верхних слоях; rulesets реализуют контракты core)
```

## Точки входа

- [`index.ts`](./index.ts) — публичный API пакета: реэкспорт типов и функций всех слоёв. При добавлении нового экспорта обновляйте его здесь.
- Тесты — в [`../tests`](../tests); архитектурные спецификации — в [`../docs/specs`](../docs/specs).

Общий обзор проекта: [`../README.md`](../README.md)
