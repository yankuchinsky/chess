# Chess Kernel Documentation

Добро пожаловать в документацию проекта **Chess Kernel** — абстрактного движка для настольных игр с поддержкой кастомных правил, топологий и адаптеров рендеринга.

## 📖 О проекте

Chess Kernel — это не просто шахматный движок, а фреймворк для создания любых настольных игр на доске. Архитектура разделена на три уровня:

1. **Ядро (Core)** — абстрактная математика доски, топологии, состояние игры
2. **Правила (RuleSets)** — конкретные реализации игр (шахматы, Crazyhouse, гексагональные шахматы)
3. **Адаптеры (Adapters)** — рендеринг и ввод (CLI, Web, UCI, мобильные приложения)

### Ключевые особенности

- ✅ **Топология-агностик**: поддержка прямоугольных, гексагональных и произвольных досок
- ✅ **Кастомные правила**: легко добавить свою игру через интерфейс `RuleSet`
- ✅ **Неизменяемое состояние**: безопасная история ходов, undo/redo из коробки
- ✅ **Любой рендеринг**: ядро не зависит от UI, подключайте что угодно
- ✅ **TypeScript**: полная типизация, декларации включены в сборку
